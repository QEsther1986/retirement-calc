# 01 — 先讀我：這套工具能做到什麼

這份文件的目的是讓你在投入時間之前，先有正確的期待。請花五分鐘讀完。

---

## 一、你原本的問題

你說想要「像百萬電商說的那樣：從自動選品到自動製作短影音，且上矩陣式架到 FB、TikTok、IG，整個流程都自動化的聯盟行銷神器」。

這件事**技術上做得到**，而且已經幫你做好了。但有幾個部分跟外面課程講的不太一樣，我必須先講清楚，免得你花了錢跟時間才發現。

---

## 二、整條流程長什麼樣

```

  │ 2. 自動寫稿  │  Claude 依商品真實資料寫腳本、字幕、貼文文案、hashtag
  └──────┬──────┘  內建護欄：不編造規格、不宣稱療效、不用絕對化用語
         ↓
  ┌─────────────┐
  │ 3. 自動配音  │  免費台灣中文語音（可選男聲／女聲、可調語速）
  └──────┬──────┘
         ↓
  ┌─────────────┐
  │ 4. 自動剪片  │  1080×1920 直式，模糊背景＋商品圖＋推鏡
  └──────┬──────┘  上方大字重點＋下方字幕＋可選背景音樂
         ↓
  ┌─────────────┐
  │ 5. 人工審核  │  ← 預設開啟。影片做好會停下來等你看過
```

一次執行大約 2~5 分鐘做一支影片（看你的電腦速度和網路）。

## 三、四個你一定要知道的限制

### 限制 1：Instagram 不能直接上傳影片檔

這是 Meta 官方的限制，不是工具做不到。IG 的發佈 API 只接受一個「公開網址」，由 Instagram 自己去把影片抓回去。

**你的選擇：**

| 做法 | 難度 | 費用 |
|---|---|---|
| 用 Cloudflare Tunnel 把本機資料夾暫時變公開網址 | 中 | 免費 |
| 把影片丟到物件儲存（Cloudflare R2 / AWS S3） | 中 | 幾乎免費 |
| IG 改成手動發（影片和文案工具都幫你準備好） | 低 | 免費 |

**我的建議：一開始 IG 就用手動發。** IG 的演算法不會因為你手動發而給你比較差的觸及，而且手動發你可以順手把連結放到限時動態，轉換率反而更好。等 FB 和 TikTok 都跑順了再來處理 IG 自動化。

詳細做法見 `04-申請各平台API.md`。

### 限制 2：TikTok 直接公開發佈需要通過審核

TikTok 把「用 API 直接公開發影片」列為需要審核的功能（Content Posting API audit）。沒通過之前，你就算呼叫成功，影片也只會是「僅自己可見」。

**工具的預設做法：** 發到你 TikTok App 的「草稿匣」。你打開手機 App，看到影片已經在那裡，點兩下就發出去了。文案工具也幫你存成文字檔，複製貼上即可。

這個模式**不需要任何審核**，申請完開發者帳號馬上能用。等你確定要放大規模，再去送審。

### 限制 3：蝦皮開放 API 要另外申請

有蝦皮分潤帳戶 ≠ 有開放 API 權限。API 要在聯盟後台另外申請，而且不是每個人都會過。

**申請不到怎麼辦？** 用 CSV 模式。你在蝦皮聯盟後台自己挑好商品、產生分潤連結，貼進一個試算表檔案，剩下的（寫稿、配音、剪片、發佈）全部自動。

實務上很多人長期都是這樣做，因為**選品本來就是最需要人判斷的一步**。花 20 分鐘挑 30 件好商品，可以讓工具自動做一整個月的影片。

### 限制 4：自動化的是「生產」，不是「流量」

這點最重要，也最常被課程模糊帶過。

這個工具能讓你從「一支影片做兩小時」變成「一支影片兩分鐘」。生產力提升幾十倍是真的。

但是：**發一百支沒人看的影片，收入還是零。**

真正決定收入的是：
- **選品**：這件商品有沒有人想買？佣金夠不夠？（工具的評分只是輔助，你的判斷仍然關鍵）
- **鉤子**：前 3 秒有沒有讓人停下來？
- **測試**：哪一類商品、哪一種講法有反應？這要你看數據調整。

工具幫你把時間從「做影片」挪到「想選品、看數據」。這才是它真正的價值。

## 四、要花多少錢

| 項目 | 費用 | 說明 |
|---|---|---|
| 這個工具本身 | 免費 | 程式碼都在你的電腦上 |
| Python / ffmpeg | 免費 | 開源軟體 |
| 中文配音 | 免費 | 微軟 Edge 語音，不用註冊 |
| Claude API（寫文案） | **約 NT$2~3 / 支影片** | 用 claude-opus-5 估算 |
| 蝦皮聯盟 | 免費 | 你已經有帳號了 |
| FB / IG / TikTok API | 免費 | 開發者帳號免費 |
| 影片託管（只有 IG 自動發才需要） | 免費～NT$30/月 | Cloudflare 免費額度通常就夠 |

**實際估算：** 一天 3 支、一個月 90 支 → Claude API 大約 **NT$180~270 / 月**。

想再省的話，把 `config.yaml` 的 `content.model` 改成 `claude-sonnet-5`，費用大約降到一半，文案品質仍然很好。完全不想付費也可以不填 API 金鑰，工具會用內建的樣板文案（品質普通，但流程照跑）。

## 五、我建議的推進節奏

**第 1 週：先確認做得出東西**
- 用 demo 模式跑，看看影片長什麼樣
- 調 `config.yaml` 的版面設定，調到你滿意的樣子
- 這週不要碰任何社群帳號

**第 2 週：換成真商品，但手動發**
- 用 CSV 模式，自己挑 20~30 件商品填進去
- `publish.require_approval` 保持 `true`
- 只開 `manual` 模式，影片和文案自己上傳
- 觀察：AI 寫的文案你能接受嗎？哪種商品的腳本比較好？

**第 3~4 週：開自動發佈，從一個平台開始**
- 先開 Facebook 粉專（申請最簡單、限制最少）
- 一天 2~3 支就好，不要一次衝量
- 看數據：哪些商品有點擊？哪些完全沒反應？

**穩定之後：才開矩陣**
- 確定內容有效之後，再加第二、第三個帳號
- 不同帳號建議做不同的商品分類，不要完全複製同樣內容

**不要一開始就開五個帳號全自動狂發。** 那是最快被封號的路線，而且你根本還不知道什麼內容有效。
