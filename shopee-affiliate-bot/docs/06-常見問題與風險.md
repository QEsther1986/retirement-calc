## 第一部分：出錯了怎麼辦

### 通則

遇到任何問題，先跑這個：

```bash
python run.py doctor
```

它會逐項檢查並告訴你缺什麼、怎麼補。

還是不行的話，看 `logs/bot.log`（用記事本開就行），最後面就是錯誤原因。
看不懂的話把那段貼給我，我可以直接告訴你問題在哪。

### 常見錯誤對照表

| 訊息 | 意思 | 怎麼處理 |
|---|---|---|
| `找不到設定檔 config.yaml` | 忘記複製設定檔 | `cp config.example.yaml config.yaml` |
| `設定檔格式有誤，YAML 無法解析` | 縮排用到 Tab，或冒號後面沒空格 | 檢查你改過的那幾行，縮排一律用空格 |
| `找不到 ffmpeg` | ffmpeg 沒裝或沒重開終端機 | 重開終端機；還是不行就重裝 |
| `找不到中文字型` | Linux 缺字型 | `sudo apt install fonts-noto-cjk` |
| `所有商品圖都下載失敗` | 圖片網址錯了或圖床擋你 | 檢查 CSV 的 `image_urls`；或改用本機圖片路徑 |
| `沒有商品通過篩選條件` | 選品門檻太嚴 | 調低 `min_sales` / `min_commission_rate`，或先跑 `python run.py pick` 看狀況 |
| `配音失敗，改用靜音音軌` | 連不到微軟語音服務 | 檢查網路；影片還是做得出來，只是沒聲音 |
| `蝦皮 API 回應 401/403` | 金鑰錯、沒開通、或電腦時間不準 | 檢查 `.env`；校正系統時間（簽章有時效） |
| `蝦皮 API 回報查詢錯誤` | 蝦皮改了欄位名稱 | 在 `config.yaml` 的 `source.shopee.query` 貼上官方最新查詢語法 |
| `Facebook 錯誤，代碼 190` | 權杖過期（約 60 天） | 重跑 `python tools/meta_setup.py` |
| `Facebook 錯誤，代碼 200` | 權限不足 | 產生權杖時要勾 `pages_manage_posts` |
| `Instagram 缺少 video_url_base` | 沒設定影片公開網址 | 見 `04-申請各平台API.md`，或 IG 改手動發 |
| `Instagram 處理影片時失敗` | IG 抓不到你的影片網址 | 用瀏覽器開那個網址確認能下載 |
| `TikTok 換發權杖失敗` | refresh_token 過期（約 365 天） | 重跑 `python tools/tiktok_auth.py` |
| `unaudited_client_can_only_post...` | TikTok 應用程式沒過審核 | 把 `tiktok.mode` 改成 `draft` |

### 影片做出來但是怪怪的

| 狀況 | 調哪裡（`config.yaml` 的 `video:` 區塊） |
|---|---|
| 字幕被商品圖蓋住 | 調小 `product_image_size`，或調大 `subtitle_bottom` |
| 字太大跑出畫面 | 調小 `headline_size` / `subtitle_size`，或調小每行字數 |
| 字幕一行太長 | 調小 `subtitle_chars_per_line` |
| 影片太長 | 調小 `content.target_seconds` |
| 講太慢 | 把 `voice_rate` 改成 `+15%` |
| 想換聲音 | `voice` 改成 `zh-TW-YunJheNeural`（男聲） |
| 畫面切太快 | 調大 `segment_gap_seconds` |

改完直接再跑一次，不用重裝任何東西。

## 第二部分：帳號安全

### 什麼行為容易被封號

**高風險（不要做）**
- 大量註冊假帳號
- 同一分鐘內多個帳號發一模一樣的內容
- 新帳號第一天就發 10 支以上
- 買粉、互讚群組
- 文案裡放縮網址服務的連結（部分平台會判定為可疑連結）

**中風險（小心）**
- 每支影片都是同一個模板、同樣配音、同樣配色
- 完全不回留言、不互動的帳號
- 只發帶貨內容，沒有任何其他貼文

**低風險（建議做法）**
- 每天固定 2~3 支，穩定經營
- 不同帳號做不同分類、用不同的視覺風格
- 偶爾發一些非帶貨的內容（開箱心得、生活分享）
- 回留言

### 工具做了哪些保護

- 多帳號之間預設間隔 90~120 秒（`gap_seconds`）
- 同一件商品 30 天內不會重複做（`dedupe_days`）
- 文案 AI 有合規護欄，不會寫出誇大不實的內容
- 預設開啟人工審核，你看過才發

### 工具不會做的事

這個工具**不會、也不應該**用來：
- 自動註冊帳號
- 繞過平台的頻率限制
- 偽裝成不同的人或裝置
- 大量洗版

這些行為違反所有平台的使用條款，會導致帳號被整批永久停權。
工具支援多帳號，是為了讓你管理**自己真實擁有的**多個帳號，不是為了洗版。

## 第三部分：法規與責任

### 這些事情你必須知道

**1. 貼文要標示是分潤合作**

台灣公平交易委員會對「薦證廣告」有規範：如果你因為推薦商品而獲得報酬，
必須揭露這個關係。工具產生的文案結尾會自動加上：

> 本影片含蝦皮分潤連結，購買不影響您的價格。

**不要把這句話刪掉。**

**2. 不可以誇大不實**

`公平交易法` 第 21 條禁止對商品做虛偽不實或引人錯誤的表示，可處罰鍰。
所以工具的 AI 護欄禁止：
- 編造商品沒有的規格、成分、功效
- 宣稱療效（治療、改善疾病、減肥）
- 用「最」「第一」「保證」「100%」這類絕對化用語
- 捏造「我用了三個月」這種不存在的親身經歷

但是 **AI 有可能出錯**。所以人工審核那一關很重要。

**3. 特定商品有額外規範**

食品、化妝品、醫療器材、保健食品的廣告規範特別嚴（`食品安全衛生管理法`、
`化粧品衛生安全管理法` 等），罰則也重。

工具預設的 `exclude_keywords` 已經幫你排除了「藥」「醫療」「減肥」等關鍵字。
**新手建議先避開這些類別。**

**4. 音樂與圖片的版權**

- 背景音樂一定要用可商用、無版權爭議的音樂。用有版權的音樂，影片會被平台靜音或下架。
- 商品圖用蝦皮商品頁的圖，一般在聯盟行銷的合理使用範圍內，但如果賣家有特別聲明就要尊重。
- 自己拍的照片最安全，也最有辨識度。

**5. 責任歸屬**

內容是從你的帳號發出去的，法律上的責任在你身上，不在工具或 AI 身上。
這也是為什麼我把人工審核設成預設開啟。

## 第四部分：常見疑問

**Q：這樣真的能賺到「百萬電商」講的那種錢嗎？**

老實說：工具能自動化的是「生產」，不是「流量」。

它能讓你從一支影片做兩小時變成兩分鐘，生產力提升是真的。
但發一百支沒人看的影片，收入還是零。

真正決定收入的是選品眼光、鉤子寫得好不好、以及你有沒有看數據調整。
工具幫你把時間從剪片挪到這些事情上——這才是它的價值。

任何跟你說「裝了這個就會自動賺錢」的人，你要小心。

**Q：一開始該投入多少時間？**

第一週大概要花 3~5 小時（安裝、設定、挑商品、調版面）。
之後每天 10~20 分鐘（看影片、審核、看數據）。

**Q：可以完全不看、完全自動嗎？**

技術上可以（`require_approval: false` + 排程）。
但我建議至少跑一個月人工審核再說，理由見上面的法規段落。

**Q：影片會不會被說是 AI 做的然後被降觸及？**

平台目前主要看「內容對觀眾有沒有價值」，而不是「是不是 AI 做的」。
會被降觸及的通常是：畫面粗糙、沒有資訊量、純搬運。

想提升品質的具體做法：
- 用自己拍的商品照（`image_urls` 可以填本機檔案路徑）
- 加上你自己的使用心得（在 CSV 多加一欄，或自己改文案）
- 不同影片換不同配色、配音

**Q：我改壞了怎麼辦？**

`config.example.yaml` 是原始範本，永遠不會被改動。
把 `config.yaml` 刪掉重新複製一份就回到初始狀態。

跑 `python tests/test_basics.py` 可以確認程式邏輯還是正常的。

**Q：資料會不會被傳到哪裡去？**

- 商品資料、影片、資料庫都在你自己的電腦上
- 只有在你設定了 Claude API 金鑰時，商品的「文字資料」（名稱、價格、銷量）會送去產生文案
- `.env` 的金鑰不會被傳到任何地方，只用來呼叫你自己授權的服務

**Q：可以改成別的電商平台嗎（momo、PChome）？**

可以。程式的商品來源是模組化的（`src/affiliate_bot/sources/`）。
最簡單的方式是不管哪個平台，都整理成 CSV 餵進去，其他流程完全不用改。
