# 05 — 每日操作與自動排程

---

## 每天的操作（有人工審核，建議前一個月都這樣）

一天花不到 10 分鐘。

### 早上：產出影片

```bash
cd shopee-affiliate-bot
python run.py run
```

約 5~10 分鐘後跑完，`output/` 裡會有今天的影片。

### 看一下影片（這步不要跳過）

打開 `output/` 資料夾，播放每支 mp4，確認：

- [ ] 價格、銷量、評分講得對不對
- [ ] 有沒有講出商品資料裡沒有的東西（編造規格）
- [ ] 字幕有沒有破圖、有沒有被商品圖蓋住
- [ ] 配音念得順不順

同時打開同名的 `.txt`（在 `output/待發佈/`）看貼文文案。

### 發佈

確認沒問題就：

```bash
python run.py approve all
```

只想發其中幾支的話：

```bash
python run.py approve 12 13
```

（數字是 `python run.py status` 顯示的編號）

### 看結果

```bash
python run.py status
```

## 完全自動（用熟了再開）

確定 AI 文案品質穩定之後，打開 `config.yaml`：

```yaml
publish:
  require_approval: false    # 從 true 改成 false
```

改完之後 `python run.py run` 就會做完影片直接發佈，不會停下來等你。

> **我的建議是至少跑滿一個月的人工審核再關。** 你需要知道 AI 在什麼情況下會寫出
> 你不想發的東西。而且台灣的廣告法規對不實陳述有罰則，內容是你的帳號發的，
> 責任在你身上。

## 設定成每天自動執行

### Windows（工作排程器）

1. 按 Windows 鍵，輸入 `工作排程器`，開啟
2. 右邊點 **建立基本工作**
3. 名稱填 `蝦皮影片自動化` → 下一步
4. 觸發程序選 **每天** → 下一步
5. 設定開始時間（建議早上 8:00） → 下一步
6. 動作選 **啟動程式** → 下一步
7. 填入：
   - **程式或指令碼**：`python`
   - **新增引數**：`run.py run`
   - **開始位置**：你的專案完整路徑，例如 `C:\Users\你的名字\Desktop\shopee-affiliate-bot`

   > 「開始位置」一定要填，不然程式找不到設定檔。

8. 完成

想確認有沒有成功執行，看 `logs/bot.log`。

### Mac（crontab）

1. 打開終端機，執行：

   ```bash
   crontab -e
   ```

   （第一次會問你要用哪個編輯器，選 `nano` 最簡單）

2. 在最後一行加上（把路徑換成你自己的）：

   ```
   0 8 * * * cd /Users/你的名字/Desktop/shopee-affiliate-bot && /usr/local/bin/python3 run.py run >> logs/cron.log 2>&1
   ```

   意思是「每天早上 8:00 執行」。

3. 按 `Ctrl + O` → Enter 存檔 → `Ctrl + X` 離開

4. 確認有設定成功：

   ```bash
   crontab -l
   ```

> `python3` 的完整路徑用 `which python3` 查。
> Mac 可能會跳出權限請求視窗，要允許終端機存取資料夾。

### 排程的注意事項

- **電腦要開著**，睡眠中不會執行
- 如果有開人工審核，排程只會做影片，不會發佈（你還是要自己 `approve`）
- 建議搭配 `--count` 控制數量：`run.py run --count 2`

## 發文頻率的建議

這部分沒有標準答案，但有一些普遍成立的原則：

| 階段 | 建議頻率 | 理由 |
|---|---|---|
| 第 1~2 週 | 一天 1~2 支 | 先確認內容不會被檢舉、看哪種商品有反應 |
| 第 3~4 週 | 一天 2~3 支 | 有數據了，開始放量測試 |
| 穩定後 | 一天 3~5 支 | 再多通常邊際效益遞減 |
| 矩陣多帳號 | 每個帳號一天 2~3 支 | **不要每個帳號發一模一樣的內容** |

**新帳號特別注意**：剛開的帳號一天就狂發 10 支，被判定為機器人的機率很高。
前兩週每天 1~2 支，讓帳號有正常的活動軌跡。

工具的 `gap_seconds` 設定（帳號之間的間隔）預設 90~120 秒，不建議調低。

## 矩陣帳號的正確做法

工具支援多帳號，但「矩陣」不等於「同樣內容複製貼上到十個帳號」。
那樣做的結果通常是十個帳號一起被限流。

比較有效的做法：

1. **不同帳號做不同分類**
   - 帳號 A 專做廚房用品
   - 帳號 B 專做 3C 配件
   - 帳號 C 專做寵物用品

   在 `config.yaml` 用不同的 `products.csv`（或不同的 `keywords`），
   分別跑不同的設定檔。

2. **不同帳號用不同聲音和版面**

   改 `config.yaml` 的 `video.voice`（男聲/女聲）和 `headline_color`，
   讓影片看起來不是同一個模板出來的。

3. **錯開發文時間**

   不要十個帳號同一分鐘發文。`gap_seconds` 就是在做這件事。

### 怎麼跑多組設定

複製整個資料夾，或用不同的設定檔：

```bash
# 廚房用品帳號
cd shopee-affiliate-bot-廚房
python run.py run

# 3C 帳號
cd shopee-affiliate-bot-3C
python run.py run
```

每個資料夾有自己的 `config.yaml`、`.env`、`products.csv` 和資料庫。

## 調整選品條件

改完 `config.yaml` 的 `selection` 區塊之後，先用這個指令看效果，不用真的做影片：

```bash
python run.py pick
```

它會印出會選到哪些商品、各項得分多少。覺得選出來的東西不對，就回去調權重。

常見調整：

| 你想要 | 怎麼改 |
|---|---|
| 選更便宜的東西 | 調低 `price_sweet_low` / `price_sweet_high` |
| 佣金更重要 | 調高 `weights.commission` |
| 只要熱賣款 | 調高 `min_sales` |
| 避開某類商品 | 在 `exclude_keywords` 加關鍵字 |
| 同一件商品可以更快重推 | 調低 `dedupe_days` |
