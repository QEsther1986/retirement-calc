# 03 — 安裝步驟

從完全乾淨的電腦開始，照著做就好。Windows 和 Mac 分開寫，找你自己的那一段。

整個過程大約 15~20 分鐘，大部分時間在等下載。

---

## Windows

### 步驟 1：安裝 Python

1. 打開 https://www.python.org/downloads/
2. 點藍色大按鈕「Download Python 3.x.x」
3. 執行下載的檔案
4. **⚠️ 最重要的一步**：安裝畫面最下面有一個勾選框 **「Add python.exe to PATH」**，**一定要打勾**，再按 Install Now

   （沒打勾的話，後面所有指令都會出現「python 不是內部或外部命令」）

5. 裝完按 Close

### 步驟 2：安裝 ffmpeg（做影片用的）

1. 按 Windows 鍵，輸入 `powershell`
2. 在「Windows PowerShell」上按**右鍵** → 「以系統管理員身分執行」
3. 貼上這行，按 Enter：

   ```powershell
   winget install Gyan.FFmpeg
   ```

4. 裝完之後**把 PowerShell 關掉，重新開一個**（這樣新的路徑才會生效）

> 如果 `winget` 說找不到指令，代表你的 Windows 版本較舊。改用這個方法：
> 到 https://www.gyan.dev/ffmpeg/builds/ 下載 `ffmpeg-release-essentials.zip`，
> 解壓縮到 `C:\ffmpeg`，然後把 `C:\ffmpeg\bin` 加到系統環境變數 Path。
> 加環境變數的步驟：按 Windows 鍵 → 輸入「環境變數」→ 編輯系統環境變數 →
> 環境變數 → 在「系統變數」找到 Path → 編輯 → 新增 → 貼上 `C:\ffmpeg\bin` → 確定。

### 步驟 3：拿到這個專案

如果你已經有這個資料夾了，跳過這步。

如果是從 GitHub 下載：網頁右上角綠色的「Code」按鈕 → Download ZIP → 解壓縮到你找得到的地方（例如桌面）。

### 步驟 4：安裝套件

1. 打開**檔案總管**，進到 `shopee-affiliate-bot` 資料夾
2. 在上面的網址列點一下，把內容全選刪掉，輸入 `powershell` 再按 Enter
   （這樣會直接在這個資料夾開啟 PowerShell，不用打 cd）
3. 貼上：

   ```powershell
   pip install -r requirements.txt
   ```

4. 等它跑完（大約 2~3 分鐘）

### 步驟 5：建立設定檔

在同一個 PowerShell 視窗貼上：

```powershell
copy config.example.yaml config.yaml
copy .env.example .env
```

### 步驟 6：檢查

```powershell
python run.py doctor
```

看到綠色打勾就對了。有紅色 ❌ 的話，它會告訴你缺什麼、怎麼補。

## Mac

### 步驟 1：安裝 Homebrew（如果還沒有）

1. 按 `Command + 空白鍵`，輸入 `終端機`，按 Enter
2. 貼上這行，按 Enter，照畫面指示輸入你的電腦密碼：

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

   （輸入密碼時螢幕不會顯示任何東西，這是正常的，打完直接按 Enter）

3. 裝完之後，畫面最後會叫你再執行兩行 `echo ...` 開頭的指令，照著做

### 步驟 2：安裝 Python 和 ffmpeg

```bash
brew install python ffmpeg
```

等它跑完（大約 5 分鐘）。

### 步驟 3：進到專案資料夾

```bash
cd ~/Desktop/shopee-affiliate-bot
```

（把路徑換成你實際放的位置。小技巧：輸入 `cd ` 之後，直接把資料夾從 Finder 拖進終端機視窗，路徑會自動填好）

### 步驟 4：安裝套件

```bash
pip3 install -r requirements.txt
```

### 步驟 5：建立設定檔

```bash
cp config.example.yaml config.yaml
cp .env.example .env
```

### 步驟 6：檢查

```bash
python3 run.py doctor
```

> **Mac 注意**：如果 `python` 指令說找不到，就把所有指令的 `python` 都改成 `python3`。

## 確認裝好了

執行：

```bash
python run.py run --count 1
```

（Mac 用 `python3`）

大約 2~3 分鐘後，`output/` 資料夾裡會出現一支 `.mp4`。打開來看看。

**這支影片用的是假商品資料，不要發到任何平台。** 它的目的只是確認你的電腦做得出影片。

## 裝不起來的常見狀況

| 錯誤訊息 | 原因 | 解法 |
|---|---|---|
| `python 不是內部或外部命令` | 安裝 Python 時沒勾 Add to PATH | 重新安裝 Python，記得打勾 |
| `找不到 ffmpeg` | ffmpeg 沒裝或沒重開終端機 | 重開終端機再試；還是不行就重裝 ffmpeg |
| `pip 不是內部或外部命令` | 同 Python PATH 問題 | 改用 `python -m pip install -r requirements.txt` |
| `找不到設定檔 config.yaml` | 忘記複製設定檔 | 執行步驟 5 的 copy / cp 指令 |
| 字幕變成空白方框 | 缺中文字型 | Windows/Mac 內建都有；Linux 執行 `sudo apt install fonts-noto-cjk` |
| `Permission denied` (Mac) | 權限問題 | 指令前面加 `sudo`，然後輸入電腦密碼 |

還是卡住的話，把 `logs/bot.log` 的內容貼給我看，我可以直接告訴你問題在哪。
