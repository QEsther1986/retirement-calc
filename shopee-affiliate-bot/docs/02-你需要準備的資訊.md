# 02 — 你需要準備哪些資訊

你問「需要給你什麼必要資訊」。這份文件就是答案。

分成三批：**第一批不用給我任何東西就能跑**，第二、三批再視你要開哪些功能決定。

---

## ⚠️ 最重要的安全原則

**不要把下面任何一個東西貼在對話裡給我，或貼給任何人：**

- API 金鑰、Secret、存取權杖（access token）
- 蝦皮、Facebook、Instagram、TikTok 的帳號密碼
- 任何看起來像 `sk-ant-...`、`EAAG...`、`act.xxx...` 的長字串

這些東西等同你的帳號密碼。你要做的是**自己把它們填進 `.env` 檔案**，那個檔案只存在你自己的電腦上。

我可以教你每一步怎麼點、怎麼複製貼上，但我不需要、也不應該看到它們的內容。

---

## 第一批：現在就能跑，不用準備任何東西

直接執行就能看到影片成品：

```bash
python run.py doctor
python run.py run --count 1
```

用的是內建的示範商品和本機產生的圖片，連網路都不需要。

**這一步的目的**：確認你的電腦裝得起來、做得出影片、影片長相你能接受。

---

## 第二批：要開始推真商品（建議第 2 週做）

### A. 商品清單（必要）

**選項 1：用 CSV（推薦，馬上可以開始）**

你需要準備一個試算表，每一列填一件商品。可以用 Excel 或 Google 試算表編輯，存成 CSV。

需要的欄位：

| 欄位 | 必填 | 怎麼拿到 | 範例 |
|---|---|---|---|
| `item_id` | ✅ | 自己編就好，不重複即可 | `a001` |
| `name` | ✅ | 蝦皮商品頁上的商品名稱 | `不鏽鋼保溫瓶 316 大容量` |
| `price` | ✅ | 商品售價（只填數字） | `459` |
| `affiliate_link` | ✅ | **你的蝦皮分潤連結** | `https://s.shopee.tw/xxxx` |
| `image_urls` | ✅ | 商品圖網址，多張用 `|` 分隔 | `https://.../1.jpg\|https://.../2.jpg` |
| `commission_rate` | 建議 | 佣金率，填 `12` 或 `0.12` 都可以 | `12` |
| `sales` | 建議 | 商品頁上的已售出數量 | `3210` |
| `rating` | 建議 | 商品評分 | `4.7` |
| `discount_rate` | 選填 | 折扣幅度，填 `45` 代表現省 45% | `45` |
| `category` | 選填 | 你自己分的類別 | `居家生活` |

> **小技巧**：`image_urls` 也可以填你自己電腦裡的圖片檔路徑（例如 `C:/我的圖/保溫瓶1.jpg`），這樣可以用你自己拍的照片，做出來的影片會更有辨識度、也比較不會跟別人撞圖。

範本在 `products.example.csv`，複製成 `products.csv` 再改。

**怎麼拿到商品圖網址**：在蝦皮商品頁，對著商品圖按滑鼠右鍵 →「複製圖片位址」。

**選項 2：申請蝦皮開放 API（全自動，但要審核）**

到蝦皮聯盟後台申請 Open API 權限。通過後你會拿到兩個值：
- App ID
- App Secret

填進 `.env` 的 `SHOPEE_APP_ID` 和 `SHOPEE_APP_SECRET`，然後把 `config.yaml` 的 `source.mode` 改成 `shopee`。

**你要告訴我的（不含機密）**：
- 你想主打哪些商品類別？（例如：居家收納、廚房用品、3C 配件、寵物用品）
- 你的目標客群大概是誰？（年齡、性別、消費習慣）
- 你希望的價格帶？（目前預設甜蜜帶是 NT$250~900）

這些我可以直接幫你調 `config.yaml` 的選品條件。

### B. Claude API 金鑰（建議，但可以先不要）

沒有的話工具會用內建樣板文案，流程照跑，只是文案比較平。

申請方式：https://console.anthropic.com → 註冊 → API Keys → Create Key

拿到一串 `sk-ant-...` 開頭的字，**自己**填進 `.env` 的 `ANTHROPIC_API_KEY=` 後面。

費用約 NT$2~3 一支影片，會先要求你儲值（最低 US$5，大約可以做 200 支影片）。

## 第三批：要開自動發佈（建議第 3 週之後）

每個平台需要的東西不一樣。詳細申請步驟在 [`04-申請各平台API.md`](04-申請各平台API.md)。

### Facebook 粉絲專頁（最建議先開這個）

你需要準備：
- [ ] 一個 **Facebook 粉絲專頁**（個人檔案不行，API 只支援粉專）
- [ ] 你是那個粉專的管理員
- [ ] 一個 Meta 開發者帳號（免費）

會拿到兩個值填進 `.env`：`FB_PAGE_ID`、`FB_PAGE_ACCESS_TOKEN`

### Instagram

你需要準備：
- [ ] IG 帳號已切換成**商業帳號或創作者帳號**
- [ ] 該 IG 帳號已**連結到上面那個 Facebook 粉專**
- [ ] 一個能放影片的公開網址（見 `04` 文件）

會拿到：`IG_USER_ID`、`IG_ACCESS_TOKEN`

### TikTok

你需要準備：
- [ ] 一個 TikTok 帳號
- [ ] 一個 TikTok 開發者帳號（developers.tiktok.com，免費）

會拿到三個值：`TIKTOK_CLIENT_KEY`、`TIKTOK_CLIENT_SECRET`、`TIKTOK_REFRESH_TOKEN`

### 矩陣（多帳號）

如果你要做多帳號，每多一個帳號就多一組上面的值。在 `.env` 裡用不同的變數名稱（例如 `FB_PAGE_ID_2`），然後在 `config.yaml` 的 `accounts` 底下多加一組設定。

**再強調一次**：請用你自己真實擁有、正常經營的帳號。大量註冊假帳號違反所有平台條款，會被整批封鎖，工具也不是為那個目的做的。

## 整理成一張清單

現在就可以做（不用準備任何東西）：

- [ ] 跑 `python run.py doctor`
- [ ] 跑 `python run.py run --count 1`，打開 `output/` 看影片
- [ ] 覺得字太大/太小/位置不對？改 `config.yaml` 的 `video:` 區塊再跑一次

要推真商品時：

- [ ] 準備 20~30 件商品的 CSV（或申請蝦皮 API）
- [ ] （可選）申請 Claude API 金鑰
- [ ] 告訴我你想主打的類別、客群、價格帶 → 我幫你調選品條件

要開自動發佈時：

- [ ] 建好粉絲專頁
- [ ] IG 切成商業帳號並連結粉專
- [ ] 申請 Meta / TikTok 開發者帳號
- [ ] 照 `04-申請各平台API.md` 一步步拿到金鑰，自己填進 `.env`
- [ ] 跑 `python run.py doctor` 確認每一項都打勾
