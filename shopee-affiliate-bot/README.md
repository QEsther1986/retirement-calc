# 蝦皮聯盟行銷自動化工具

從「自動選品」到「自動做短影音」到「自動發佈到 Facebook / Instagram / TikTok」的一條龍工具。

你完全不需要會寫程式。所有操作都是：**打開終端機、貼上一行指令、按 Enter**。

---

## 先看這個：它能做到什麼、做不到什麼

**能做到（已經寫好、測試過）**

| 功能 | 說明 |
|---|---|
| 自動選品 | 依「單件利潤、分潤率、銷量」三項為主（另加評價、折扣）自動評分排序，預設對應「利潤高、分潤高、銷售量高」的選品規則，並自動避開最近推過的商品 |
| 自動寫腳本 | 用 Claude 產生短影音腳本、字幕、貼文文案與 hashtag，內建「不誇大、不編造」的合規護欄 |
| 自動配音 | 免費的台灣中文語音（男聲／女聲可選），不用申請帳號 |
| 自動做影片 | 1080×1920 直式短影音，含模糊背景、緩慢推鏡、上方大字、下方字幕、可選背景音樂 |
| 自動發佈 | Facebook 粉專 Reels、Instagram Reels、TikTok，支援多帳號矩陣，帳號之間自動間隔 |
| 人工審核關卡 | 預設「影片做好先停下來等你看過」，你確認才發出去（可關閉） |
| 紀錄與去重 | 每支影片、每次發佈都記錄在本機資料庫，同一件商品不會重複推 |

**做不到 / 你必須知道的限制**

1. **不保證賺錢。** 這個工具自動化的是「production 生產流程」，不是「流量」。內容能不能紅、有沒有人買，取決於選品眼光和內容品質，不是取決於發了幾支。所謂「百萬電商」的關鍵通常在選品與測試，不在自動發佈本身。
2. **Instagram 不能直接上傳檔案。** IG 的 API 只接受「公開網址」，你必須把影片放到一個網路上抓得到的地方。詳見 `docs/04-申請各平台API.md`。
3. **TikTok 直接公開發佈需要審核。** 沒通過 TikTok 的 Content Posting API 審核之前，只能發到「草稿匣」（你在手機上點一下就能發）或「僅自己可見」。工具預設用草稿模式。
4. **蝦皮開放 API 要另外申請。** 不是有分潤帳號就自動有 API 權限。申請不到也沒關係，用 CSV 模式一樣能全自動。
5. **矩陣帳號請用你自己真實擁有的帳號。** 工具支援多帳號，但大量註冊假帳號洗版違反所有平台的使用條款，而且會被整批封鎖。這個工具不會、也不應該用來做那件事。

## 五分鐘快速開始

```bash
# 1. 進到這個資料夾
cd shopee-affiliate-bot

# 2. 安裝需要的套件
pip install -r requirements.txt

# 3. 建立你自己的設定檔
cp config.example.yaml config.yaml
cp .env.example .env
#    Windows 請把 cp 改成 copy

# 4. 檢查環境有沒有問題（很重要，它會告訴你缺什麼、怎麼補）
python run.py doctor

# 5. 用內建的示範資料跑一次，確認電腦做得出影片
python run.py run --count 1
```

第 5 步跑完，`output/` 資料夾裡就會有一支 mp4。打開來看看，確認影片長相符合你的期待。

接著照 `docs/` 裡的文件一步步換成你自己的真實商品與帳號。

## 常用指令

| 指令 | 做什麼 |
|---|---|
| `python run.py doctor` | 檢查環境與設定，會明確告訴你缺什麼、怎麼補 |
| `python run.py pick` | 只看這次會選到哪些商品，不做影片（調整選品條件時很好用） |
| `python run.py run` | 完整執行：選品 → 寫腳本 → 做影片 →（審核後）發佈 |
| `python run.py run --count 5` | 這次做 5 支 |
| `python run.py run --no-publish` | 只做影片，完全不碰發佈 |
| `python run.py approve all` | 把待審核的影片全部發出去 |
| `python run.py approve 3 4` | 只發佈第 3、4 支 |
| `python run.py status` | 看最近做了哪些影片、發佈成功還失敗 |
| `python run.py test-shopee` | 實際打一次蝦皮 API，檢查它有沒有回傳銷量、評分等你要篩選的欄位 |
| `python tests/test_basics.py` | 跑基本邏輯測試（改過設定後想確認沒弄壞可以跑） |

## 資料夾結構

```
shopee-affiliate-bot/
├── run.py                  ← 你只會用到這個檔案
├── config.example.yaml     ← 設定範本（複製成 config.yaml 再改）
├── .env.example            ← 金鑰範本（複製成 .env 再填）
├── products.example.csv    ← 商品清單範本（CSV 模式用）
├── requirements.txt        ← 需要安裝的套件清單
├── docs/                   ← 說明文件
├── tests/                  ← 測試
├── output/                 ← 做好的影片放這裡（自動產生）
│   └── 待發佈/              ← 手動模式的影片＋文案
├── logs/                   ← 執行紀錄，出問題時看這裡
├── data/                   ← 本機資料庫（記錄推過哪些商品）
└── src/affiliate_bot/      ← 程式本體
    ├── sources/            ← 商品從哪裡來（蝦皮 API / CSV / 示範）
    ├── media/              ← 圖片、配音、影片合成
    └── publish/            ← 各平台發佈
```

## 安全提醒

- `.env` 裡面是等同你帳號密碼的東西，**絕對不要傳給任何人、不要上傳到網路**。這個專案已經設定好不會把它上傳到 GitHub。
- 剛開始請保持 `config.yaml` 的 `publish.require_approval: true`（發佈前人工審核）。確認 AI 寫的文案品質穩定之後再考慮關掉。
- 背景音樂一定要用可商用、無版權爭議的音樂，否則影片會被平台靜音或下架。
